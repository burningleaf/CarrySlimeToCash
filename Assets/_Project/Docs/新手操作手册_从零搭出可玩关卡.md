# 零基础操作手册：把 Demo 变成能玩的东西

> 你现在的位置：脚本已放进工程、编译通过。
> 目标：**先做出一个 20 分钟能跑起来的最小测试关**，确认玩法对不对，再逐步加内容。
> 使用方式：从头按顺序做，每个阶段末尾有 ✅ 验收，验收不过就不要往下走。

**一条铁律**：Unity 里按了 ▶ Play 之后的任何修改，停止播放后都会丢失。所以**先改、再保存、再 Play**。

---

## 阶段 0：认识界面 + 三个必查设置（5 分钟）

### 0.1 认识 5 个区域

```
┌─────────────────────────────────────────────────────┐
│ ① 菜单栏                              ▶ Play 按钮    │
├──────────┬────────────────────────┬─────────────────┤
│ ②Hierarchy│      ③Scene           │  ④Inspector     │
│ 场景里有  │   在这里摆放物体        │  选中物体的属性  │
│ 哪些物体  │  （左上角点 2D 按钮）    │                 │
├──────────┴────────────────────────┴─────────────────┤
│ ⑤Project：工程里的文件（脚本、场景、图片都在这里）      │
└─────────────────────────────────────────────────────┘
```

操作三件套，记牢就够用了：
- **选中**：在 Hierarchy 或 Scene 里点一下物体，Inspector 就会显示它。
- **加组件**：Inspector 最下面 `Add Component` → 在搜索框里打名字。
- **拖引用**：把 Hierarchy 里的物体**拖到 Inspector 的字段框里**（这是最容易卡住的一步，拖错了不会有任何提示，只会没反应）。

### 0.2 必查一：输入设置（最重要，错了后面全都不动）

`Edit → Project Settings → Player → Other Settings → Active Input Handling`

必须是 **`Input Manager (Old)`** 或 **`Both`**。
如果显示 `Input System Package (New)`：改成 `Both` → 弹窗点 `Apply` → Unity 会重启一次。

> 原因：我们的脚本用的是旧版输入 `Input.GetAxisRaw`，新输入系统下会直接报错。

### 0.3 必查二：Game 视图分辨率

点 ▶ Play 之前，在 Game 视图**左上角**把分辨率设成 `16:9 Aspect`（或 `Fixed Resolution 1920x1080`）。

### 0.4 必查三：场景视图切到 2D

Scene 视图左上角有个 `2D` 按钮，点一下变成蓝色。这样视角不会乱转。

✅ **验收**：你按下 ▶ Play 再按一次能停下来，游戏视图是黑/蓝色的空画面。

## 阶段 1：建 Layer 和 Tag（10 分钟，只建，先不配矩阵）

`Edit → Project Settings → Tags and Layers`

### 1.1 建 Tag

展开 **Tags**，你会看到 `Element 0` 之类。点右下角 `+` → 输入名字 → 回车。重复 11 次：

```
Player    Slime    Enemy    MovingPlatform    Coin    SlimeOrb
Hazard    Goal    Checkpoint    PressurePlate    Gate
```

### 1.2 建 Layer（顺序很重要，必须对号入座）

展开 **Layers**，从 **User Layer 6** 开始，一格一格填：

| 格 | 名字 |
|---|---|
| User Layer 6 | `Player` |
| User Layer 7 | `Slime` |
| User Layer 8 | `CarriedSlime` |
| User Layer 9 | `Ground` |
| User Layer 10 | `Platform` |
| User Layer 11 | `MovingPlatform` |
| User Layer 12 | `Hazard` |
| User Layer 13 | `Enemy` |
| User Layer 14 | `Pickup` |
| User Layer 15 | `TriggerZone` |
| User Layer 16 | `Gate` |

> **不要动 Builtin Layer 那一组**（Default / TransparentFX / Ignore Raycast / Water / UI）。
> 索引必须和上表一致 —— 脚本里的 `slimeLayer = 7`、`carriedLayer = 8` 是按这个表写死的。

✅ **验收**：随便选一个物体，Inspector 右上角的 `Layer` 下拉里能看到 `Player / Slime / Ground ...`。

## 阶段 2：搭最小测试场景（30 分钟，最关键的一段）

### 2.1 新建并保存场景

1. 菜单 `File → New Scene` → 选 **`Basic 2D (Built-in)`** → `Create`
   > - 列表里还有 `Basic 2D (URP)` 等带后缀的项：**后缀必须和你工程的渲染管线一致**，选错了所有精灵会变成粉红色。
   > - 怎么查：`Edit → Project Settings → Graphics → Scriptable Render Pipeline Settings`。为空 = Built-in；有值（URP Asset）= URP。
   > - **不要选 `Empty`**：空场景连相机都没有，Game 视图会显示 `No cameras rendering`，还得自己建一台正交相机。
   > - `Basic 2D` 已经替你建好一台 **Main Camera（Projection = Orthographic）**，正是我们要的。
2. `File → Save As` → 定位到 `Assets/_Project/Scenes`（没有 Scenes 文件夹就在 Project 面板里右键 `Create → Folder` 建一个）
3. 文件名填 `Test` → 保存

> 场景文件必须放在 `Assets` 里面，否则不会被打包。

### 2.2 铺地面（用方块代替美术）

用方块拼，不需要任何美术资源。

**做法（重复 3 次）**：菜单 `GameObject → 2D Object → Sprites → Square`
> 如果找不到这个菜单：Project 面板右键 `Create → 2D → Sprites → Square` 先生成资源，再把它拖进 Scene。

然后按下面这张表改 Inspector 里 Transform 的 `Position` 和 `Scale`，并把右上角 `Layer` 改掉：

| 物体名 | Position | Scale | Layer | 作用 |
|---|---|---|---|---|
| `Ground_A` | `(-6, -1, 0)` | `(16, 2, 1)` | `Ground` | 左半地面（顶面 y=0） |
| `Ground_Pit` | `(3, -3, 0)` | `(4, 2, 1)` | `Ground` | 坑底（比地面低 2 格） |
| `Ground_B` | `(10, -1, 0)` | `(12, 2, 1)` | `Ground` | 右半地面（顶面 y=0） |

**给这三个方块都加碰撞体**：选中 → `Add Component` → 搜 `Box Collider 2D` → 回车。
（默认 Size 是 1×1，会自动跟着 Scale 缩放，不用改。）

> 做完这三块，中间 x 在 2~4 之间就是一道 **2 格宽、2 格深的坑**。

### 2.3 建玩家

1. `GameObject → 2D Object → Sprites → Square` → 改名 `Player`
2. Transform：`Position (-8, 0.6, 0)`、`Scale (0.8, 1.2, 1)`
3. 右上角 `Layer` 选 `Player`
4. `Add Component` 依次加：
   - `Rigidbody 2D`，然后按下面设：
     | 属性 | 值 |
     |---|---|
     | Gravity Scale | `3` |
     | Collision Detection | `Continuous` |
     | Interpolate | `Interpolate` |
     | Constraints | 展开，勾上 `Freeze Rotation Z` |
   - `Box Collider 2D`（默认值即可）
   - `Player Controller`
   - `Player Inventory`
   - `Player Grab`
   - `Audio Source`（可选，先不加也行）
5. 在 Hierarchy 里**右键 `Player` → `Create Empty`**，改名 `GroundCheck`：
   - 选中 `GroundCheck`，Transform Position 改成 `(0, -0.6, 0)`
6. 再**右键 `Player` → `Create Empty`**，改名 `CarryPoint`：
   - Transform Position 改成 `(0.3, 0.9, 0)`

> `GroundCheck` 和 `CarryPoint` 必须是 `Player` 的**子物体**（在 Hierarchy 里缩进一层），不能是同级。

### 2.4 建史莱姆

1. `GameObject → 2D Object → Sprites → Square` → 改名 `Slime`
2. Transform：`Position (-10, 0.5, 0)`、`Scale (0.9, 0.9, 1)`
3. 右上角 `Layer` 选 `Slime`
4. `Add Component` 依次加：
   - `Rigidbody 2D`：Gravity Scale `4`、Collision Detection `Continuous`、Interpolate `Interpolate`、Constraints 勾 `Freeze Rotation Z`
   - `Circle Collider 2D`（默认 Radius 0.5 即可）
   - `Slime Controller`
   - `Slime Path Follow`
   - `Audio Source`（可选）
5. **右键 `Slime` → `Create Empty`** → 改名 `GroundCheck` → Position 改成 `(0, -0.45, 0)`

### 2.5 建两个管理对象

1. `GameObject → Create Empty` → 改名 `GameManager` → 加组件 `Game Manager`
2. `GameObject → Create Empty` → 改名 `LevelManager` → 加组件 `Level Manager`

### 2.6 设置相机

选中 `Main Camera`（`Basic 2D` 模板已经建好了；如果你的场景里没有相机，先 `GameObject → Camera` 建一台并把 `Projection` 改成 `Orthographic`），Inspector 里：

| 属性 | 值 |
|---|---|
| Position | `(1, 0, -10)` |
| Projection | `Orthographic` |
| Size | `9` |
| Background | 随便挑个深色 |

> 先不用 Cinemachine，固定相机能看全整关，方便调试。等跑通了再换成跟随相机。

### 2.7 ★ 拖引用（这一步最容易漏，漏一个就没反应）

**依次选中物体，把 Hierarchy 里的东西拖进 Inspector 的空框里：**

#### 选中 `Player`

| 组件 | 字段 | 拖什么进去 |
|---|---|---|
| Player Controller | Body | 可以留空（代码会自动找 Rigidbody 2D） |
| Player Controller | Ground Check | 拖子物体 `GroundCheck` |
| Player Controller | Sprite Root | **留空** |
| Player Controller | Ground Layer | 点开下拉，勾上 `Ground`、`Platform`、`MovingPlatform` |
| Player Inventory | Player | 拖 `Player` 自己 |
| Player Grab | Player | 拖 `Player` 自己 |
| Player Grab | Inventory | 拖 `Player` 自己（会自动取到 Player Inventory 组件） |
| Player Grab | Slime | 拖场景里的 `Slime` |
| Player Grab | Path Follow | 拖场景里的 `Slime`（会自动取到 Slime Path Follow 组件） |
| Player Grab | Carry Point | 拖子物体 `CarryPoint` |
| Player Grab | Slime Layer Mask | 勾上 `Slime` 和 `CarriedSlime` |

#### 选中 `Slime`

| 组件 | 字段 | 拖什么进去 |
|---|---|---|
| Slime Controller | Body / Body Collider | 可以留空（自动找） |
| Slime Controller | Player | 拖 `Player` |
| Slime Controller | Path Follow | 拖 `Slime` 自己 |
| Slime Controller | Level Manager | 拖 `LevelManager` |
| Slime Controller | Ground Check | 拖子物体 `GroundCheck` |
| Slime Controller | Sprite Root / Sprite Renderer | **留空** |
| Slime Controller | Ground Layer | 勾上 `Ground`、`Platform`、`MovingPlatform` |
| Slime Path Follow | Slime | 拖 `Slime` 自己 |
| Slime Path Follow | Player | 拖 `Player` |
| Slime Path Follow | Waypoint Prefab | **留空**（阶段 5 再建） |

#### 选中 `LevelManager`

| 字段 | 拖什么进去 |
|---|---|
| Slime | 拖 `Slime` |
| Player | 拖 `Player` |
| Start Point | 拖 `Player`（意思是用玩家的初始位置当复活点） |

`GameManager` 不用拖任何东西。

### 2.8 ▶ Play 验收（第一个里程碑）

点 ▶ Play，然后用键盘测试：

| 操作 | 键 | 期望结果 |
|---|---|---|
| 左右移动 | `A` / `D` 或 `←` `→` | 玩家方块左右移动 |
| 跳跃 | `空格` | 能跳约 3 格高 |
| 抱起史莱姆 | 走近史莱姆按 `E` | 史莱姆贴到玩家身上，玩家变慢、跳变低 |
| 放下 | 再按 `E` | 史莱姆留在原地 |
| 投掷 | 按 `Q`（抱着时） | 史莱姆被斜着扔出去 |
| 切物品 | `1` `2` `3` | Inspector 里 Player Inventory 的 Current Slot 会变 |
| 哨子切换模式 | 按 `2` 再按 `E` | 史莱姆原地不动（Stay），再按 `E` 恢复跟随 |
| 暂停 | `Esc` | 暂时没反应（PauseMenu 还没做，正常） |

史莱姆应该表现出：
- 贴地跟着玩家走，**明显慢半拍**
- 玩家跳起来后约 **0.2 秒**它才跟着跳
- 走到 2 格宽的坑边会**停在边缘不下去**（这是对的，`stopAtLedge`）
- 你抱着它跳过坑，放下，它继续跟着走

**卡在哪里先别往下走**，直接跳到本文最后的「常见故障排查」对照解决。

## 阶段 3：加关卡元素（20 分钟）

### 3.1 尖刺（危险区）

1. `GameObject → 2D Object → Sprites → Square` → 改名 `Hazard_Spike`
2. Transform：`Position (7, 0.25, 0)`、`Scale (1.5, 0.5, 1)`
3. Layer 选 `Hazard`
4. 加 `Box Collider 2D` → **勾上 `Is Trigger`**
5. 加 `Hazard` 组件 → `Damage` 填 `20`、`Level Manager` 拖 `LevelManager`

✅ 让史莱姆从尖刺上走过去 → Inspector 里 Slime Controller 的 `Current Health` 从 100 掉到 80，方块闪一下。

### 3.2 金币和回血球

1. 复制 `Hazard_Spike`（`Ctrl+D`）→ 改名 `Coin_1` → Layer 改 `Pickup`
2. Transform：`Position (9, 0.5, 0)`、`Scale (0.5, 0.5, 1)`
3. 把 `Hazard` 组件删掉（Inspector 组件右上角 `⋮` → `Remove Component`），改成加 `Coin` 组件 → `Level Manager` 拖 `LevelManager`
4. 复制出 `Coin_2`，Position 改 `(11.5, 0.5, 0)`
5. 再复制一个改名 `Orb_1`，Position `(5, 0.5, 0)`，把 `Coin` 换成 `Slime Orb` 组件 → `Slime` 拖 `Slime`

✅ 只有史莱姆能吃金币（Inspector 里 LevelManager 的 Current Coins 会增加），**玩家自己走过去吃不到**（现在还吃得到，因为你还没配碰撞矩阵，阶段 4 会修好）。

### 3.3 收购站（通关点）

1. `GameObject → 2D Object → Sprites → Square` → 改名 `Goal`
2. Transform：`Position (14, 1, 0)`、`Scale (2, 2, 1)`
3. Layer 选 `TriggerZone`
4. 加 `Box Collider 2D` → **勾 `Is Trigger`**
5. 加 `Goal` 组件 → `Level Manager` 拖 `LevelManager`

✅ 让史莱姆走进收购站 → Inspector 里 LevelManager 的 `Level Finalised` 相关值变化：`Level Finished` 打勾、`Final Coins` 有数字。

### 3.4 算一下钱对不对

血量 100 / 时间很短时，`Final Coins` 应该接近 `100 × 1.0 × 1.5 = 150`。
如果史莱姆掉了 20 血再进收购站：`100 × 0.8 × 时间奖励`，大约是 120~120。

### 3.5 （可选）验证"必须靠携带"的高台

在左边加一个悬空平台，让史莱姆上不去：

1. 复制 `Ground_A` → 改名 `Ledge_High`
2. Transform：`Position (-11, 3.5, 0)`、`Scale (4, 1, 1)`
3. 在它上面放一个金币 `Position (-11, 4.3, 0)`

✅ 玩家跳上去没问题（3 格跳跃刚好够）；引导史莱姆过去，它会在墙边**卡住不动** —— 这就是设计里的"遇到高台卡住，等玩家处理"，此时你必须用抱起或投掷把它弄上去。

## 阶段 4：配碰撞矩阵（15 分钟，一次性，之后不用再动）

`Edit → Project Settings → Physics 2D` → 展开最下面的 **Layer Collision Matrix**。

> 这是一张"行 × 列"的勾选表，**勾上 = 这两层会碰撞**。默认全都是勾上的。
> 你要做的是：**把下面这些格子里的勾点掉**（点一下就切换）。

### 4.1 必须取消的（玩法靠它成立）

| 取消哪一格 | 为什么 |
|---|---|
| `Pickup` × `Player` | **金币只对史莱姆生效**，小孩物理上吃不到 |
| `Pickup` × `Ground`、`Pickup` × `Platform`、`Pickup` × `MovingPlatform` | 金币不和地形纠缠 |
| `Hazard` × `Ground`、`Hazard` × `Platform`、`Hazard` × `MovingPlatform` | 危险区不和地形纠缠 |
| `Hazard` × `Enemy` | 怪物不怕尖刺 |
| `Enemy` × `Pickup` | 怪物不吃金币 |
| `Player` × `Slime` | 玩家走过去不该推挤史莱姆 |
| `CarriedSlime` × **除 `TriggerZone` 以外的所有层**（共 10 格） | 抱着史莱姆时免伤、不推挤玩家 |
| `Enemy` × `Enemy`、`Slime` × `Slime`、`Ground` × `Ground`、`MovingPlatform` × `MovingPlatform`、`Gate` × `Gate` | 自己和自己不碰，避免抖动 |
| `Platform` × `Ground`、`Platform` × `MovingPlatform` | 单向平台不和地形碰 |

> `CarriedSlime` 那 10 格是重点：`Player / Slime / CarriedSlime / Ground / Platform / MovingPlatform / Hazard / Enemy / Pickup / Gate` **全部点掉**，只留 `TriggerZone` 是勾的（这样抱着史莱姆进收购站也算通关）。

### 4.2 确认这些必须是勾上的

`Player`、`Slime` 各自与 `Ground`、`MovingPlatform`、`Hazard`、`Enemy`、`TriggerZone`、`Gate`；
`Slime` 与 `Pickup`；`Enemy` 与 `Ground`、`MovingPlatform`、`TriggerZone`、`Gate`。
（默认就是勾上的，除非你手误点掉了。）

✅ **验收**：玩家自己走到金币上，金币**不会消失**；史莱姆走过去就吃掉。
✅ **验收**：抱着史莱姆从尖刺上走过去，史莱姆**不掉血**。

## 阶段 5：做成预制体（10 分钟）

预制体（Prefab）= 一个可以反复复用的模板。做三个就够：

1. 在 Project 面板 `Assets/_Project/Prefabs` 下建文件夹 `Player`、`Slime`、`Items`
2. 把 Hierarchy 里的 `Player` **拖到** Project 的 `Prefabs/Player` 文件夹里 → 图标变蓝，说明成了预制体
3. 同样把 `Slime` 拖到 `Prefabs/Slime`，把 `Coin_1` 拖到 `Prefabs/Items`
4. 做路径点预制体：`GameObject → Create Empty` → 改名 `WaypointMarker` → 加 `Waypoint Marker` 组件 → 再给它加一个子物体 `Square`（Scale 0.3）当圆点 → 把整个 `WaypointMarker` 拖到 `Prefabs/Slime`
5. 回到场景，选中 `Slime`，把 `Slime Path Follow` 的 **Waypoint Prefab** 拖成刚做的 `WaypointMarker` 预制体
6. 再建一个空物体 `WaypointContainer`，拖进 `Slime Path Follow` 的 **Waypoint Container**

✅ 按 `3` 切到引导石 → 在几个地方按 `E` 放 3 个路径点 → 按 `2` 切哨子 → `E` 切成 Stay → 再 `E` 切回 Follow：
史莱姆会**按你放置的顺序依次走过这 3 个点，最后走到你身边**，然后恢复常规跟随。

## 阶段 6：关卡 + UI + 场景流程（建议单独开一轮）

到这一步你已经有一个能玩通的关卡了。剩下的是"包装"：

1. 复制 `Test` 场景 → 改名 `Level1`，照着设计文档把关卡摆得更有意思
2. 建 `MainMenu` / `LevelSelect` 场景，放 Canvas + 按钮
3. `File → Build Settings` → 把 5 个场景按顺序拖进去（MainMenu=0、LevelSelect=1、Level1=2…）
4. 每个场景的 Canvas 上挂 `UIManager` / `InventoryUI` / `PauseMenu` / `LevelResult`，按 SETUP 手册的连线表拖引用
5. 装 Cinemachine（`Window → Package Manager → Unity Registry → Cinemachine`），把 Main Camera 换成跟随相机

> 这一阶段的连线表在 `SETUP_工程搭建与场景连线.md` 第 6–7 节，比本手册更细。
> 建议先把阶段 2~5 玩熟，再开这一轮 —— 一次性做太多会很难定位问题。

## 常见故障排查

| 现象 | 原因与解法 |
|---|---|
| 按 A/D 完全不动，控制台报错 | `Active Input Handling` 不是 Old/Both → 回去看阶段 0.2 |
| 角色一直往下掉、穿过地面 | 地面方块的 Layer 不是 `Ground`，或 Player Controller 的 `Ground Layer` 没勾 `Ground` |
| 角色能动但跳不起来 | `GroundCheck` 位置不对（要在脚底），或它不是 Player 的子物体 |
| 史莱姆站着不动 | Slime Controller 的 `Player` 或 `Ground Layer` 没配；或 `GroundCheck` 位置太高 |
| 史莱姆滑来滑去不跟人 | `Follow Distance` 太大，调小到 1.4；或 Player 没拖 |
| 按 E 抱不起来 | `Player Grab` 的 `Slime Layer Mask` 没勾 `Slime`；或离得太远（判定半径 1.2，约一个身位） |
| 控制台一堆 `NullReferenceException` | 阶段 2.7 的引用表里漏拖了字段，按报错里提到的脚本名回去补 |
| Play 里改的东西停了就没了 | 正常现象。要么在非 Play 状态改，要么改完在 Inspector 组件右上角 `⋮ → Copy Component`，停止后再 `Paste Component Values` |
| 金币被玩家吃掉了 | 阶段 4 的碰撞矩阵没配 |
