# 《带呆呆史莱姆越障换钱》2D 横版 Demo —— 设计文档（施工规格）

- 引擎：Unity 2022.3 LTS，Universal 2D / 2D (URP) 模板（Built-in 2D 工程同样可用，本 Demo 不依赖 URP 特性）
- 语言：C#
- 输入：旧版 Input Manager（Input.GetAxisRaw / GetButtonDown / GetKeyDown）
- 组件：Rigidbody2D、Collider2D、Cinemachine、Tilemap、TextMeshPro
- 禁用：CharacterController2D、一切付费插件
- 单位约定：**1 格 = 1 Unity 单位 = 1 Tile**（Grid Cell Size = 1，美术 16×16 像素，Pixels Per Unit = 16）

---

## 0. 技术底线（自检清单）

| 约束 | 落地方式 |
| --- | --- |
| 不用事件系统 | 无 UnityEvent / C# event / Action；跨脚本一律 `public` 引用拖拽 + 直接调方法 |
| 不用接口 | 物品、状态、模式全部 enum + switch |
| 不用 ScriptableObject | 所有参数写成 `public` 字段，Inspector 调 |
| 不用 InputManager 类 | 直接在脚本里读 Input（键位用 GetKeyDown + 两个默认轴） |
| 不用 AudioManager | 每个物体自带 AudioSource，自己 PlayOneShot |
| 不用 SaveManager | 直接 PlayerPrefs |
| 不用 SceneLoader | 直接 SceneManager.LoadScene |
| 保留 GameManager | 只做暂停 / 重开 / 退出，不碰游戏数据 |
| 禁止 FindObjectOfType | 全部 public 引用拖拽；抓取判定用 Physics2D.OverlapCircle + public LayerMask |
| 禁止攀爬/寻路/传送/A*/NavMesh | 史莱姆只有"直线蠕动 + 延迟跟随 + 跟跳 + 路径点"，卡住就等玩家 |
| 禁止硬编码数值 | 所有速度、血量、伤害、延迟、半径都是 public 字段 |

依赖方向严格单向：**UI → 逻辑 → 数据**，逻辑层绝不引用 UI 层。

## 3. 每个脚本的职责与依赖关系

### 3.1 依赖总图（箭头 = "持有 public 引用并调用"）

```
                     ┌──────────────┐
                     │  GameManager │  （零逻辑依赖，只操作 timeScale / SceneManager）
                     └──────▲───────┘
                            │ UI 调用
   ┌────────────┬───────────┴────────┬───────────────┐
   │ PauseMenu  │   LevelResult      │ MainMenu / LevelSelectUI
   └────────────┘                    └───────────────┘
        ▲                    ▲
        │ 拉数据              │ 拉数据
   ┌────┴────────────────────┴───────────────┐
   │            LevelManager                 │  ◄── 只被 UI 读 + 被逻辑层汇报
   └────▲──────────────▲──────────────▲──────┘
        │              │              │
   ┌────┴─────┐  ┌─────┴──────┐  ┌────┴─────┐
   │ Player   │  │  Slime     │  │ Level 交互 │  Hazard / Goal /
   │ Controller│ │ Controller │  │ PressurePlate / Checkpoint /
   │ Inventory│  │ PathFollow │  │ Enemy / MovingPlatform
   │ Grab     │  │ Waypoint   │  └──────────┘
   └──────────┘  └────────────┘        ▲
        ▲                              │ 只对史莱姆生效
        └──────── Coin / SlimeOrb ─────┘
```

**四条硬规则：**
1. 逻辑层（Player/Slime/Level/Items/Managers）**绝不引用 UI 层**。UI 主动拉数据（UIManager、LevelResult、InventoryUI 每帧或状态变化时读逻辑脚本）。
2. `LevelManager` 是唯一的"汇报出口"：金币、结算、失败、检查点都走它。
3. `PlayerGrab` 是唯一的动作键入口（E / Q），其他脚本不读 E / Q。
4. 史莱姆只读玩家数据（位置、在地面、是否起跳、朝向），玩家不写史莱姆内部状态（只能通过 PlayerGrab / 哨子调用其 public 方法）。

### 3.2 Managers

#### GameManager（Managers/GameManager.cs）
- **职责**：全局暂停开关（Time.timeScale = 0 / 1）、重新开始当前关卡、退出到关卡选择、退出游戏。不做任何游戏数据。
- **依赖**：无（只依赖 SceneManager 与 Application）；UI 反向调用它。
- **public 字段**：`levelSelectSceneName = "LevelSelect"`、`restartDelay = 0.6`、`pauseTimeScale = 0`。
- **public 方法**：`TogglePause()`、`SetPaused(bool)`、`RestartLevel()`、`ExitLevel()`、`QuitGame()`；属性 `IsPaused`。
- **说明**：不使用 DontDestroyOnLoad，每个场景各放一个 GameManager 预制体（便于任意场景直接 Play 调试）；Esc 由 PauseMenu 读取并调用 `SetPaused`。
- **禁止**：不引用 PauseMenu（保持无 UI 依赖）。

#### LevelManager（Managers/LevelManager.cs）
- **职责**：关卡内唯一数据中枢。
  - 金币计数 `AddCoin(int)`；
  - 计时（`totalTime` 累加）；
  - 结算：`FinalCoins = basePrice × (currentHealth / maxHealth) × timeBonus`；星级按最终金币分档；
  - 史莱姆死亡 → 关卡失败 → 延迟自动重开；
  - 玩家死亡 → 回到最近 Checkpoint（保留金币）；
  - 记录检查点、解锁下一关、写 PlayerPrefs（金币 / 星级 / 解锁位）。
- **依赖**：`SlimeController`、`PlayerController`（读血量与复活点）、`Goal` 不反向依赖（Goal 调它）；SceneManager。
- **public 字段**：`basePrice = 100`、`parTime = 60`、`timeBonusMax = 1.5`、`timeBonusMin = 0.5`、`timeBonusFalloffPerSecond = 0.01`、`starThresholds = {60, 120, 180}`（按最终金币）、`failRestartDelay = 1.5`、`playerRespawnDelay = 1.0`、`levelIndex = 1`（决定解锁 `LevelUnlocked_{levelIndex+1}`）。
- **public 方法**：`AddCoin(int)`、`OnSlimeReachedGoal()`、`OnSlimeDied()`、`OnPlayerDied()`、`SetCheckpoint(Vector3)`、`GetRespawnPoint()`、`RestartLevel()`。
- **只读属性**：`CurrentCoins`、`TotalTime`、`SlimeHealth`、`SlimeMaxHealth`、`HealthRatio`、`TimeBonus`、`FinalCoins`、`Stars`、`LevelFinished`、`LevelFailed`。

### 3.3 Player

#### PlayerController（Player/PlayerController.cs）
- **职责**：水平移动、跳跃、地面/斜坡检测、携带状态、玩家死亡与检查点复活、Animator 参数、音效。
- **依赖**：Rigidbody2D、BoxCollider2D、groundCheck 子物体、Animator（可空）、AudioSource；`PlayerGrab`（读 `IsCarrying`）；`LevelManager`（死亡 → 复活）。
- **public 字段**：
  | 字段 | 建议值 | 说明 |
  | --- | --- | --- |
  | `moveSpeed` | 6.5 | 空手水平速度 |
  | `carryMoveMultiplier` | 0.6 | 携带史莱姆时的移速倍率 |
  | `acceleration` / `deceleration` | 60 / 70 | 加減速手感 |
  | `gravityScale` | 3.0 | 由 Rigidbody2D 使用 |
  | `jumpHeight` | 3.0 | **格**，空手约 3 格 |
  | `carryJumpHeight` | 1.8 | **格**，携带时 1.5–2 格 |
  | `coyoteTime` | 0.10 | 离地宽限 |
  | `jumpBufferTime` | 0.12 | 预输入 |
  | `maxFallSpeed` | 25 | 下落限速 |
  | `groundCheckRadius` | 0.18 | 圈检测 |
  | `groundLayer` | Ground\|Platform\|MovingPlatform | public LayerMask |
  | `airControl` | 0.8 | 空中控制系数 |
  | `deathFallY` | -20 | 掉出关卡即死亡 |
- **关键实现**：跳跃初速由 `jumpHeight × |Physics2D.gravity.y × gravityScale|` 计算（不写死数字）；不实现攀爬、爬墙、抓边、翻越；Animator 参数（Speed / IsGrounded / IsCarrying / IsDead）在本脚本内写。
- **禁止**：不读 E / Q 键；不改史莱姆状态。

#### PlayerInventory（Player/PlayerInventory.cs）
- **职责**：`enum ItemType { None, Whistle, GuideStone, Slot4 }` + switch 管理 4 个槽位；数字键 1–4 切换（GetKeyDown）；携带史莱姆时禁止切换。
- **依赖**：`PlayerGrab`（读 `IsCarrying`）；`InventoryUI`（不反向引用，UI 自己来读）。
- **public 字段**：`ItemType[] slots = new ItemType[4]`、`currentSlot = 0`、`allowSwitchWhileCarrying = false`、`KeyCode[] slotKeys = { Alpha1, Alpha2, Alpha3, Alpha4 }`、`switchSound`。
- **对外**：属性 `CurrentItem`、`CurrentSlot`、`IsSwitchLocked`；方法 `SelectSlot(int)`、`GetSlot(int)`。
- **switch 表**：None→空手；Whistle→哨子；GuideStone→引导石；Slot4→预留（切换时若为空则忽略）。

#### PlayerGrab（Player/PlayerGrab.cs）
- **职责**：唯一的 E / Q 入口，按 `PlayerInventory.CurrentItem` 用 switch 分发：
  | 物品 | E（GetKeyDown(KeyCode.E)） | Q（GetKeyDown(KeyCode.Q)） |
  | --- | --- | --- |
  | None 空手 | 未携带 → 抓取（半径内）；已携带 → 放置 | 已携带 → 投掷；未携带 → 无 |
  | Whistle 哨子 | 切换史莱姆 Follow / Stay | 召回（再按 Q 打断召回） |
  | GuideStone 引导石 | 在玩家站位放一个路径点（最多 3 个） | 清除全部路径点 |
  | Slot4 | 预留 | 预留 |
- **依赖**：`PlayerInventory`、`PlayerController`、`SlimeController`、`SlimePathFollow`（均为 public 引用拖拽）、AudioSource。
- **public 字段**：`grabRadius = 1.2`（**宽容判定**）、`slimeLayerMask`（public LayerMask）、`carryPoint`（Transform，挂在玩家头顶/身前）、`placeOffsetX = 0.8`、`placeOffsetY = 0.1`、`throwForceForward = 5`、`throwForceUp = 9`、`regrabDelay = 0.35`、`grabSound / throwSound / placeSound`。
- **抓取流程**：`Physics2D.OverlapCircle(transform.position, grabRadius, slimeLayerMask)` → 命中则 `slimeController.EnterCarried(carryPoint)`，玩家 `SetCarrying(true)`。
- **放置**：放在面前 `placeOffsetX` 处，**不改变史莱姆的 Follow / Stay 模式**（模式只由玩家主动切换）。
- **投掷**：解除携带 → Rigidbody2D 转 Dynamic → 切回 Slime 层 → `velocity = (facing × throwForceForward, throwForceUp)` → 进入 Thrown，落地后回到投掷前的模式。
- **哨子召回定义**：史莱姆以 `recallSpeedMultiplier` 倍速**沿直线朝玩家方向蠕动**，遇高台/深坑照样卡住（不寻路、不绕路、不传送）；再按 Q 取消召回。
- **注意**：进入 Carried 时把史莱姆 layer 切到 `CarriedSlime`，脱离时切回 `Slime`（这是"携带时不被怪物和危险区命中"的实现手段）。

### 3.4 Slime

#### SlimeController（Slime/SlimeController.cs）
- **职责**：核心状态机 + 血量。
  `enum SlimeState { Follow, Stay, Scared, Carried, Thrown, Dead }`
  | 状态 | 行为 |
  | --- | --- |
  | Follow | 有路径点 → 交给 SlimePathFollow 沿点走；无路径点 → 延迟常规跟随（位置历史缓冲）+ 跟跳 |
  | Stay | 原地不动，保留血量与朝向 |
  | Scared | 受击后触发：停止移动 + 抖动表现 + 无敌帧，`scaredDuration` 后回到 `prevState` |
  | Carried | 由 PlayerGrab 驱动：bodyType = Kinematic，跟随挂点，切层到 CarriedSlime |
  | Thrown | 自由落体，落地后回到投掷前的模式（**不自动变 Stay**） |
  | Dead | 血量 ≤ 0 → `levelManager.OnSlimeDied()` → 关卡失败自动重开 |
- **依赖**：Rigidbody2D、CircleCollider2D、groundCheck / wallCheck 子物体、Animator、AudioSource、`SlimePathFollow`、`PlayerController`（只读）、`LevelManager`（汇报死亡）。
- **public 字段**：
  | 字段 | 建议值 | 说明 |
  | --- | --- | --- |
  | `maxHealth` | 100 | 最大血量 |
  | `currentHealth` | 100 | 运行时 |
  | `followSpeed` | 6.0 | 接近玩家速度 |
  | `recallSpeedMultiplier` | 1.4 | 哨子召回倍速 |
  | `followDistance` | 1.4 | 常规跟随保持距离 |
  | `followDelay` | 0.15 | **0.1–0.2s** 移动延迟（位置缓冲时长） |
  | `jumpFollowDelay` | 0.20 | **0.15–0.25s** 跟跳延迟 |
  | `jumpHeightRatio` | 1.0 | 跟跳高度 = 玩家跳高 × 该值 |
  | `maxStepHeight` | 0.35 | 高于此值的台阶直接卡住 |
  | `stopAtLedge` | true | 前方地面缺失时停在边缘（不下深坑） |
  | `wallCheckDistance` | 0.45 | 前方墙检测距离 |
  | `groundLayer` | Ground\|Platform\|MovingPlatform | LayerMask |
  | `slimeLayer` / `carriedLayer` | Slime / CarriedSlime | 层索引，抓取时切换 |
  | `invincibleTime` | 1.0 | 受击后无敌帧 |
  | `scaredDuration` | 0.8 | 惊吓时长 |
  | `squashAmount` / `wobbleSpeed` | 0.15 / 6 | 蠕动挤压表现 |
  | `hurtSound` / `deathSound` / `jumpSound` | — | AudioClip |
- **被调用接口**：`TakeDamage(int, Hazard)`、`Heal(int)`、`SetMode(SlimeMode)`、`EnterCarried(Transform)`、`ExitCarried(Vector2 velocity, bool thrown)`、`ToggleMode()`、`StartRecall()`、`CancelRecall()`。
- **禁止**：自主跳跃（只能跟跳）、寻路、绕路、传送、攀爬。

#### WaypointMarker（Slime/WaypointMarker.cs）
- **职责**：单个路径点。显示序号（TextMeshPro）、到达半径、被消费后的视觉变化；**不带 Collider**（判定用距离，不参与物理）。
- **依赖**：无（纯被动，被 SlimePathFollow 持有）。
- **public 字段**：`markerIndex = 0`、`arriveRadius = 0.6`、`followTarget`（Transform，可空 —— 非空时 LateUpdate 同步位置，用于"绑定在运动物体上"）、`visualRoot`、`normalColor` / `reachedColor`、`TMP_Text indexText`。
- **绑定到运动物体的两种做法**：① 直接把路径点实例拖成移动平台的子物体；② 填 `followTarget`。两者都在本脚本内支持。

#### SlimePathFollow（Slime/SlimePathFollow.cs）
- **职责**：路径点的创建、排序、推进、清空。
  - `AddWaypoint(Vector3 worldPos)`：实例化 `waypointPrefab`，编号 +1，超过 `maxWaypoints` 时拒绝（返回 false 供 UI 提示）；
  - 史莱姆距当前点 < `arriveRadius` → 标记 reached，索引 +1；
  - **Stay → Follow 切换时**：把"玩家当前所在位置"作为最后一个隐含路径点压入队列，依次走完放置顺序，最后走到人身边，靠近后自动切回常规跟随（通知 SlimeController 清 `PathMode`）；
  - `ClearAllWaypoints()`：Q 键调用；
  - 提供 `HasPendingPath`、`CurrentTarget` 给 SlimeController 使用。
- **依赖**：`SlimeController`、`PlayerController`、`WaypointMarker`（prefab + List）。
- **public 字段**：`maxWaypoints = 3`、`arriveRadius = 0.6`、`waypointPrefab`、`waypointYOffset = 0`、`usePlayerAsLastWaypoint = true`、`List<WaypointMarker> waypoints`。

#### Coin（Items/Coin.cs）
- **职责**：史莱姆碰到 → `levelManager.AddCoin(value)` + 音效 + 粒子 → 消失。
- **依赖**：`LevelManager`、AudioSource、ParticleSystem（可空）。

- **public 字段**：`healAmount = 25`、`allowOverheal = false`、`pickupSound`、`pickupEffect`、`respawnTime = 0`（>0 则一段时间后重生，可用于长关卡）。

### 3.6 Level 交互

#### Hazard（Level/Hazard.cs）
- **职责**：`enum HazardType { Spike, Water, Fire }`，触发式伤害源。
- **行为**：OnTriggerEnter2D / Stay2D 判定 `SlimeController`（`TakeDamage(damage)`，对方无敌帧内自动忽略）；判定 Player 时按 `killPlayer` 决定是否致死并交由 LevelManager 处理；对 Enemy / 物品不生效（层矩阵已排除）。
- **public 字段**：`hazardType`、`damage = 15`、`killPlayer = true`、`hitSound`、`hitEffect`、`moveOnlyOnce`（一次性伤害区，如落石）。

#### Goal（Level/Goal.cs）
- **职责**：收购站。史莱姆进入触发区 → `levelManager.OnSlimeReachedGoal()`；关闭自身防止重复结算。
- **public 字段**：`onlySlime = true`、`requireSlimeNotCarried = false`（默认允许抱着到达，因为搬运是手段之一）、`arriveSound`、`arriveEffect`、`idlePulseSpeed`。

#### PressurePlate（Level/PressurePlate.cs）
- **职责**：压力板。Player / Slime / Enemy / 移动平台压住 → 激活目标；离开 → 关闭（`stayPressed` / `oneShot` 可改）。
- **依赖**：`MovingPlatform[]`、`GameObject[] toggleObjects`（门、桥、机关），直接调 `SetActivated(bool)` / `SetActive(bool)`，**不用 UnityEvent**。
- **public 字段**：`platforms`、`toggleObjects`、`oneShot = false`、`stayPressed = false`、`requiredTag = ""`（留空 = 任意合格层）、`pressDepth = 0.08`、`pressSound` / `releaseSound`。
- **注意**：自身用 Trigger Collider，压住判定用 OnTriggerStay2D + 每帧重置的计时标记（避免多物体接触抖动）。

#### Checkpoint（Level/Checkpoint.cs）
- **职责**：检查点旗。Player 或 Slime 进入 → `levelManager.SetCheckpoint(respawnPoint.position)`；已激活则只更新视觉。
- **public 字段**：`respawnPoint`（Transform，建议放在地面上方 0.5）、`forPlayer = true`、`forSlime = true`、`activateSound`、`activeVisual`。
- **约定**：玩家碰怪死亡 → 从最近检查点复活，金币与物品保留；史莱姆死亡 → 整关失败重开。

#### Enemy（Level/Enemy.cs）
- **职责**：巡逻怪。`enum PatrolMode { Distance, EdgeDetect }`，Distance = 左右往返固定距离；EdgeDetect = 前方地面射线，悬崖/墙前转身（防掉落）。
- **行为**：碰到小孩 → 玩家死亡（`levelManager.OnPlayerDied()`，`killPlayer = true` 时可关）；碰到史莱姆 → `slimeController.TakeDamage(contactDamage)`；史莱姆被携带时不受影响（层矩阵）。
- **public 字段**：`moveSpeed = 2.5`、`patrolMode`、`patrolDistance = 3`、`groundLayer`、`wallLayer`、`contactDamage = 15`、`killPlayer = true`、`turnAtWall = true`、`animator`、`AudioSource`。
- **禁止**：不可被击杀（本 Demo 无战斗系统），不做寻路与追击（只巡逻）。

#### MovingPlatform（Level/MovingPlatform.cs）
- **职责**：`enum MoveMode { PingPong, Loop, Once }`，沿 `points[]` 固定路线移动；承载玩家与史莱姆。
- **实现要点**：kinematic Rigidbody2D + FixedUpdate 里 `MovePosition`；每帧记录 delta，在 OnCollisionStay2D 中把 delta 追加给乘客的 Rigidbody2D（**不用 parent 到平台**，避免缩放与插值问题）；乘客离开后停止补偿。
- **public 字段**：`points`（Transform[]，至少 2 个）、`speed = 2`、`waitTime = 0.5`、`moveMode`、`startActivated = true`、`carryRider = true`、`riderVelocitySmooth = 0.15`、`activatedByPlate = false`。
- **对外**：`SetActivated(bool)` 供 PressurePlate 调用。

图例：● 勾选 ／ ○ 取消 ／ △ 勾选但带附加条件

| ↓×→ | Player | Slime | Carried | Ground | Platform | Moving | Hazard | Enemy | Pickup | Trigger | Gate |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **Player** | ○ | ○ | ○ | ● | △ | ● | ● | ● | ○ | ● | ● |
| **Slime** | ○ | ○ | ○ | ● | △ | ● | ● | ● | ● | ● | ● |
| **CarriedSlime** | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ● | ○ |
| **Ground** | ● | ● | ○ | ○ | ○ | ○ | ○ | ● | ○ | ○ | ○ |
| **Platform** | △ | △ | ○ | ○ | ○ | ○ | ○ | △ | ○ | ○ | ○ |
| **MovingPlatform** | ● | ● | ○ | ○ | ○ | ○ | ○ | ● | ○ | △ | ○ |
| **Hazard** | ● | ● | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ○ |
| **Enemy** | ● | ● | ○ | ● | △ | ● | ○ | ○ | ○ | ● | ● |
| **Pickup** | ○ | ● | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ○ |
| **TriggerZone** | ● | ● | ● | ○ | ○ | △ | ○ | ● | ○ | ○ | ○ |
| **Gate** | ● | ● | ○ | ○ | ○ | ○ | ○ | ● | ○ | ○ | ○ |

**△ 说明**
- `Player/Slime/Enemy × Platform`：单向平台，勾选 + PlatformEffector2D（`useOneWay = true`），双方 Collider 都要勾 `Used By Effector`。
- `Player/Slime/Enemy × MovingPlatform`：正常实体碰撞（不是单向）。
- `MovingPlatform × TriggerZone`：仅当压力板需要"被平台压住"时才勾（Level3 可选）。
- Hazard 与 Player/Slime 勾选是因为它用 **Trigger Collider**（勾选同时保证 Trigger 事件能收到，物理上不阻挡）。

**关键取消项的设计意图**
1. `Pickup × Player = ○`：金币和史莱姆球**物理层面**就无法被小孩触发（满足"只对史莱姆生效"）。
2. `CarriedSlime × 除 TriggerZone 外全部 = ○`：抱着史莱姆穿过尖刺、穿过怪物不受伤，也不会推挤玩家（携带由挂点跟随，不需要物理）。
3. `Enemy × Hazard = ○`：巡逻怪不怕尖刺/水/火。
4. `Enemy × Enemy = ○`、`Ground × Ground = ○`、`MovingPlatform × MovingPlatform = ○`：避免抖动与自碰撞。
5. `Hazard / Pickup × Ground / Platform / MovingPlatform = ○`：触发物不需要与地形交互。
6. `TriggerZone × Pickup = ○`：避免金币掉进 Goal 区域浪费判定。

### 4.4 Rigidbody2D / Physics2D 设置

| 对象 | Body Type | Gravity Scale | Collision Detection | Interpolate | Constraints |
| --- | --- | --- | --- | --- | --- |
| Player | Dynamic | 3.0 | Continuous | Interpolate | Freeze Rotation Z |
| Slime | Dynamic | 4.0 | Continuous | Interpolate | Freeze Rotation Z |
| Enemy | Dynamic | 3.0 | Discrete | Interpolate | Freeze Rotation Z |
| MovingPlatform | Kinematic | 0 | Discrete | Interpolate | — |
| Hazard / Pickup / TriggerZone / Gate / Tilemap | Static（无 Rigidbody2D） | — | — | — | — |

Project Settings → Physics 2D：`Gravity (0, -9.81)`；`Velocity Iterations = 8`；`Queries Start In Colliders = 关闭`（避免地面圈检测命中自身）；`Queries Hit Triggers = 开启`；`Default Contact Offset = 0.01`；`Simulation Mode = Fixed Update`。

`Background(-100)` → `FarGround(-80)` → `Ground(-60)` → `Platform(-40)` → `Prop(-20)` → `Enemy(0)` → `Player(5)` → `Slime(6)` → `CarriedSlime(10)` → `Foreground(20)` → `VFX(30)`；UI 全部用 Canvas（Screen Space - Overlay）。

| **5. 收集物** | `Coin` → `SlimeOrb` | 批次 4 | 只有史莱姆能吃到；小孩走过去无反应（物理层已排除） |
| **6. UI** | `PauseMenu` → `LevelResult` → `InventoryUI` → `UIManager` → `MainMenu` → `LevelSelectUI` | 批次 1–5 | 完整流程跑通：主菜单 → 选关 → 关卡 → 结算 → 下一关；PlayerPrefs 解锁正确 |
| **7. 内容与调参** | 关卡 1 教学布局 → 关卡 2 携带/投掷 → 关卡 3 综合；预制体整理；Cinemachine 跟随与 Confiner；音效粒子 | 批次 6 | 三关可从 0 通关；数值手感调整（跳跃高度、跟随延迟、投掷力度） |

**为什么是这个顺序**：`LevelManager` 是几乎所有脚本的汇报出口，必须先有；`PlayerGrab` 依赖 `PlayerController`（携带状态）和史莱姆的 `EnterCarried/ExitCarried`，所以史莱姆排在玩家之后、但**接口先约定好**（第 3.4 节列出的被调用接口即为约定）；关卡交互件和收集物都依赖史莱姆的 `TakeDamage` / `Heal`；UI 最后做，因为它只拉数据，不阻塞任何逻辑调试（调试期用 Inspector 看 public 字段即可）。

## 7. 关键实现提示（不写代码，仅方法约定）

1. **跟跳判定**：PlayerController 暴露 `LastJumpTime`（起跳瞬间打时间戳）与 `IsGrounded`；SlimeController 在地面且 `Time.time >= LastJumpTime + jumpFollowDelay` 时给一次向上速度，速度大小 = 玩家跳跃初速 × `jumpHeightRatio`。这样"延迟 0.15–0.25 秒跟跳"天然成立。
2. **移动延迟**：SlimeController 维护环形缓冲（`Queue<(float time, Vector3 pos)>` 或定长数组），取 `Time.time - followDelay` 时刻的玩家位置作为跟随目标，实现 0.1–0.2s 的"慢半拍"。
3. **卡住检测**：`Physics2D.Raycast(wallCheck.position, facing, wallCheckDistance, groundLayerMask)` 命中点高度 − 史莱姆脚底 > `maxStepHeight` → 水平速度归零 + 播放呆滞表现；同时向下短射线判断前方地面缺失，配合 `stopAtLedge` 停在坑边。
4. **携带**：`rb.bodyType = RigidbodyType2D.Kinematic`，`rb.velocity = Vector2.zero`，切层到 CarriedSlime，在 `LateUpdate` 里 `transform.position = Vector2.Lerp(...)` 追 `carryPoint`（视觉更稳，不抖）。
5. **投掷**：恢复 Dynamic + 切回 Slime 层 + 直接赋 `velocity`，`regrabDelay` 内禁止再次抓取（避免空中连抓）。
6. **承载平台**：FixedUpdate 中 `Vector2 delta = nextPos - rb.position; rb.MovePosition(nextPos);` 然后把 `delta` 追加给本帧接触的乘客刚体（乘客 `rb.position += delta`），比 parent 更稳。
7. **结算轮询**：LevelResult 在 Update 里检查 `levelManager.LevelFinished`，用 `bool _shown` 去重；保证逻辑层零 UI 依赖。
8. **SceneManager 调用集中**：只有 GameManager / MainMenu / LevelSelectUI / LevelResult 四个脚本调 `SceneManager.LoadScene`，其余脚本不碰场景切换。
