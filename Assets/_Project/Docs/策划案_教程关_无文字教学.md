# 策划案：教程关《无声的教学》（Level 0）

> 目标：让玩家在**不看任何文字**的情况下，依次学会 9 个核心机制，并自然过渡到正式关卡。
> 手段：**用关卡本身逼出机制 + 用壁画/路标图画代替文字**。

---

## 一、设计原则

| 原则 | 说明 |
|---|---|
| **不教而教** | 不弹教程弹窗。用"地形逼出机制"——玩家遇到困难时自然去试，试出来就学会了 |
| **一次只教一件事** | 每个教学舱只引入一个新机制，其余全部是已经学会的 |
| **看 → 试 → 用** | 每个舱都是三步：**看到壁画（提示）→ 低风险试一次 → 立刻用一次拿奖励** |
| **失败无惩罚** | 教程关不放致死陷阱；掉血用"可恢复"的水，不用尖刺；每舱之间设检查点 |
| **零文字** | 所有提示都是图画；连"按 E"都不用写，用**按键图标**表示 |
| **不做教程也能玩** | 熟练玩家直接跑过去就行，壁画不妨碍通行 |

---

## 二、★ 关键前提：哪些机制**能强制**，哪些只能**演示**

这是设计前必须搞清楚的。史莱姆现在的能力是：**跟跳高度 = 玩家跳高（3 格）、会走下悬崖、会被建筑挡住**。所以"史莱姆上不去而玩家上得去"的地方**做不到**（它跟跳能力相同）。

| 机制 | 能否强制 | 强制手段 | 数值依据 |
|---|---|---|---|
| **抱起** | ✅ **能** | **危险区（水）**：史莱姆自己走会连续掉血，抱着则免伤（`CarriedSlime` 层） | 抱着走 0 伤害；自己走 16 格 ≈ 掉 40~60 血 |
| **放下** | ⚠️ **半强制** | **2.5 格高的台子**：抱着跳 1.8 格上不去，必须放下才能空手跳 3 格 | 携带跳 1.8 < 2.5 < 空手跳 3 |
| **投掷** | ✅ **能** | **4 格宽深坑**：抱着跳 2.45 格过不去，投掷 4.76 格刚好过 | 2.45 < 4 < 4.76 < 5.87 |
| **哨子 Stay** | ⚠️ **半强制** | 设计"玩家必须独自过去一趟"的路（窄缝/矮通道），史莱姆留在安全处等 | — |
| **哨子召回** | ❌ **不能强制** | 只做"便利性"演示（平地让玩家体验一下） | — |
| **引导石放点** | ✅ **能** | **1.1 格高的矮通道**：史莱姆（碰撞体 0.9）钻得过去，玩家（1.2）钻不过去 | 0.9 < 1.1 < 1.2 |
| **引导石清除** | ⚠️ **半强制** | 路径石上限 3 个，玩家放满后想改路线时会自然去找"清除" | `maxWaypoints = 3` |

> **重要**：因为"放下"和"哨子 Stay"只能半强制，教程里要**接受玩家用别的解法**（比如抱着史莱姆硬闯）。教学目标是"让他知道有这个方法"，而不是"不用这方法就过不去"。

## 五、无文字表达方案（三级）

### 第一级：**象形壁画图标**（必做，成本最低）

在**背景墙**上贴图画，位置紧挨对应机关。风格：**单色线条 + 半透明**（像刻在墙上的岩画 / 路边的告示牌），跟"扁平简洁风"一致。

**为什么可行**：这些图标全部是**几何图形**（圆 + 圆角矩形 + 箭头 + 虚线），**我可以程序化生成**，不需要外包美术。

### 第二级：**虚线路径 + 角色剪影**（推荐，表现力强很多）

在场景里放：
- 一个**半透明的玩家剪影**（静止，做着动作的姿势）
- 一条**虚线箭头**（平铺的九宫格贴图）表示运动方向
- 例：抱起教学 = 剪影举着史莱姆 + 一条虚线穿过水渠

比纯图标直观得多，成本也只是"多两个剪影贴图"。

### 第三级：**循环动画剪影**（锦上添花）

让剪影**循环播放动作**（举起→放下→举起…），像"幽灵演示"。

- 表现力最强，玩家一看就懂
- 成本：需要 4~6 个 2~4 帧的简单动画（举起 / 放下 / 投掷 / 吹哨 / 放石头 / 清石头）
- **建议放到后期做**

## 七、素材规格

| 项 | 规格 |
|---|---|
| 格式 | PNG，带 Alpha |
| 尺寸 | 图标 256×256；按键图标 128×128；虚线 64×64（九宫格） |
| 风格 | **扁平单色线条**：线宽 6~8 px（在 256 尺寸下），圆头线帽 |
| 颜色 | **白色**（`#FFFFFF`）—— 用 `SpriteRenderer.color` 在场景里 tint 成想要的色，**一张图能复用多种颜色** |
| 不透明度 | 建议最终显示 `alpha 0.35~0.5`（壁画感，不抢主体） |
| PPU | 256 尺寸的图用 **PPU = 256**（= 1 格）；128 尺寸用 PPU 128 |
| Filter | `Bilinear` |
| 压缩 | `Uncompressed` |
| Sorting Layer | 新建一层 `Background`（排在 `Ground` 之后、`Prop` 之前），`Order in Layer = -10` |

## 八、实现方式（Unity 里怎么放）

**推荐：做成一个可复用的预制体**

```
HintSign.prefab
├─ HintSign            ← 空物体，挂 HintSign.cs（可选）
│   ├─ Icon            ← SpriteRenderer，放象形图
│   └─ KeyBadge        ← SpriteRenderer，放按键图标（E / Q / 2 / 3），可空
```

**摆放规则**：
1. 每个壁画放在**对应机关的正上方或正前方**（玩家必经之路的视线高度，建议 y = 2.5~3.5 格）
2. 不透明度 0.4，`Sorting Layer = Background`，**永远不遮挡角色**
3. **不放碰撞体**（纯装饰）
4. 同一个壁画可以在场景里复用一个预制体、只换 `Icon` 的贴图

**我可以用编辑器工具批量生成**：
- 给定关卡坐标列表 → 自动 instantiate 预制体、设置贴图和颜色
- 就像现在的 `9 脚手架（默认隐藏） → 往当前场景补关卡元素` 那样

## 十一、验收标准（怎么判断教程有效）

**必须全过，否则教程没起作用**：

| # | 检验 | 通过标准 |
|---|---|---|
| 1 | **不给任何说明**，找一个人（没玩过）从 Level0 开始 | 他能走到终点 |
| 2 | 观察他**在哪里卡住** | 卡住的地方 = 壁画不够清楚，需要改 |
| 3 | 问他"水坑那里你为什么把史莱姆举起来" | 他能说出"因为壁画上画着举起来" |
| 4 | 全程**没有出现文字** | 除了 HUD 上本来就有的数字 |
| 5 | 教程时长 | **3~6 分钟**通关最理想；超过 8 分钟说明太啰嗦 |
| 6 | 三处"奖励"是否被拿到 | 通道金币、台子金币、对岸金币 —— 至少拿到 2 处 |

## 十二、和现有 Demo 的衔接

| 项 | 处理 |
|---|---|
| **放哪** | 新建 `Level0.unity`，排在 Build Settings **第 2 位**（MainMenu → LevelSelect → **Level0** → Level1 → Level2） |
| **解锁** | `Level0` 默认解锁；通关 Level0 解锁 Level1 |
| **`levelIndex`** | 设为 `0`（`SaveProgress` 会解锁 `LevelUnlocked_1` ✓ 正好接上） |
| **选关界面** | 现在需要改成 **4 张卡片**（LevelSelectUI 的数组支持 N 关 ✓ 只要在生成器里加一项） |
| **不进教程的老玩家** | 关卡选择里 Level0 的卡片文案可以是「教学 · 无声的教学」，随时可跳过 ✓ |
