设计图做完之后游戏数值改了两轮（收益公式 + 每秒掉血模型），**下面正文里的数字以本节为准**。
实际关卡数据在 `Assets/_Project/Levels/Level0.json`，那才是真相源。

### 改了什么

### 一处纠正：`Plat_1 = 2.5` 是对的，不用改

早前在 `架构_关卡数据格式与工具链.md` §4.5 里写过"放下无法用高度强制"，那是针对
"**把史莱姆放到 2.5 的台子上**"——确实做不到。

但本关的意图是"**玩家必须先放下史莱姆，才能空手跳上台子拿金币**"：
抱着跳只能 1.8 够不到 2.5，放下后空手跳 3.0 够得到 ✓ **2.5 保留**。

### 路牌：先做骨架 + 占位

15 块牌子按坐标摆好了，但**牌面上现在直接写着"以后该画什么"**（例如 `举起E`、`投掷Q`），
不是象形图。理由：教学关能不能教会人，取决于**牌子放在哪、什么时候看到**，而不是图标画得多漂亮。
位置和阅读节奏验证完之后，象形图是纯替换：把 `LevelBuilder.showMuralLabels` 关掉、填 `muralSprites` 即可。

## 六、玩家在每一舱会经历什么（逐帧推演）

### 舱1 x 0→18（约 20 秒）
1. 出生，往右走 → 发现史莱姆跟着（H1 壁画看一眼）
2. 走到 x=7 吃到第一枚金币（数字 +10，H11 小牌）
3. 继续走到 x=18 → 看到前方的水和 H2 壁画

### 舱2 x 18→34（约 40 秒）
1. **卡点**：抱着史莱姆走水渠 vs 让它自己走
   - 自己走 → 血条掉（H3 水牌 → 原来水是危险的）
   - 抬头看 H2 → **"把它举起来"** → 按 `E` ✓
2. 过水后吃到 `Orb_1` 回血（**掉的血补回来了，无惩罚**）
3. 走到 x=28 高台前 → **卡点**：抱着跳不上去
   - 看 H4 → **"蹲下放下"** → 按 `E` 放下
   - 看 H5 → 跳上去拿 `C2_2`
4. 通过 CP_1

### 舱3 x 34→52（约 30 秒）
1. 走到 x=38 → 看到 H6（抛物线）+ 4 格深坑 → **卡点**
2. 试抱着跳 → 掉水里（血掉但不死）
3. 看 H6 的 `Key_Q` → 按 `Q` 投掷 ✓ 史莱姆飞过坑
4. **落地静止 1.5 秒**（状态栏显示"投掷落地"）→ 玩家反应过来继续走
5. 通过 CP_2

### 舱4 x 52→74（约 35 秒）
1. 走到水渠前（x=58），看 H7（哨子 + 停）
2. 三种解法任选：
   - 抱着过（最省事，但慢）
   - 按 `2`+`E` 切 Stay → 自己过 → 对岸再切 Follow 让它跟过来
   - 切 Stay → 自己过 → 按 `Q` 召回（它会直线冲进水里**掉血** → 让玩家理解"召回不寻路"）
3. 过水后看 H8（召回示范）→ 在平地自己试一次召回
4. 通过 CP_3

### 舱5 x 74→102（约 60 秒，本关核心）
1. 走到 x=78 矮通道前 → **卡点**：玩家钻不进去，史莱姆钻得进去但它会跟着你
2. 看 H9（①②③ 虚线 + `Key_3` + `Key_E`）
3. 操作流程：
   - 按 `E` 放下史莱姆在通道口
   - 按 `3` 切引导石 → 在通道口按 `E` 放 **路径点1**
   - 跳上障碍顶（2.5 格）→ 走过去 → 从 x=92 跳下来
   - 按 `3` → 在通道出口按 `E` 放 **路径点2**
   - 按 `2` 切哨子 → 按 `E` 让它 **Stay**（它在通道这头）
   - 等等 —— 这里顺序要调整，见下方「操作顺序说明」
   - 按 `2` → `E` 切回 **Follow** → 史莱姆沿路径点钻过通道，**吃掉 3 枚金币**，走到你身边
4. 看 H10（清除路径石）+ 按 `Q` 试一次清除
5. 通过 CP_4

> **操作顺序说明**（这是本关最容易做错的地方，要在路牌上表达清楚）：
> **先放点 → 再切 Stay → 玩家自己走 → 在对岸切回 Follow**。
> 路牌 H9 的图要画成：小孩 → ①②③ 虚线 → 小孩（表示"你先走，它跟着虚线过来"）。

### 舱6 x 102→120（约 25 秒）
- 快速复习：水渠（抱）→ 深坑（投）
- 不引入新东西，只重复 R1 / R2 两块旧牌

### 舱7 x 120→132（约 10 秒）
1. 看 H13（钱袋）→ 走进收购站
2. **镜头平滑推近收购站**（1.2 秒）→ 结算面板

**总计约 3.5 分钟**
