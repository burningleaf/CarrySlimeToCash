## 1. 这个 demo 最终长什么样

### 1.1 一句话玩法

带着一只"呆呆"的史莱姆，穿过障碍走到回收站卖钱。**你越省时间、史莱姆越完好、路上捡的钱越多，卖价越高。**

### 1.2 一段完整的玩家流程

```
选关 → 进关 → 操作玩家（走 · 跳 · 抓 · 放下 · 扔）
     → 切物品栏（1 空手 · 2 哨子 · 3 引导石 · 4 跳跃云朵瓶）
     → 指挥史莱姆（哨子：E 停/跟 · Q 冲刺；引导石：规划路线）
     → 穿越地形与机关（水 · 坑 · 低矮隧道 · 移动平台 · 压力板与门）
     → 到达回收站（终点）→ 结算（基础价 × 血量% + 金币）→ 解锁下一关（PlayerPrefs）
```

### 4.2 物品栏 4 格 与「跳跃云朵瓶」（落盘坑 / 解密关可自由飞行）

- **四格**：`1` 空手 · `2` 哨子 · `3` 引导石 · `4` **跳跃云朵瓶**；**每关发哪几件由数据决定**（`meta.itemGrants`，四关实测都是"四件全给"），空手恒开。**2026-09-23 夜已实测"可调"真的生效**：把某关第 4 格改成 `false` → 重建后场景出现 `itemGrants.Array.data[3]` 覆盖；改回 `true` → 覆盖被清掉（场景 0 命中 = 取 prefab 默认）。
- **哨子 E/Q 分工**：`E` 管"停 / 跟"（跟随↔待命，也就是"召回"），`Q` 管"**冲刺**"（2.5 s / 冷却 3 s）；**空中无限跳已从"硬编码兜底"改成由云朵瓶赋予**，拿着云朵瓶时**不能举史莱姆**。
